FLASHING LED USING ARDUINO 
----------------------------------------
Description:
	Using an Arduino UNO to power a RGB LED module
----------------------------------------
Components:
	->Arduino UNO board (microcontroller)
	->Arduino IDE (program)
	->M wires, F wires
	->RGB LED Module (Robocraze 37 in 1 sensor kits)
-----------------------------------------

Diagram:
	view Diagram.png

------------------------------------------
Logic:
	Code switches LED Red ON, switches LED red OFF, switches LED green ON, switches LED green OFF, switches LED blue 	ON, switches LED blue OFF, and then it loops to the start
------------------------------------------
Steps:
	1. Connect Arduino uno to computer
	2. Connect IDE to board
	3. Enter Code into IDE
	4. Connect Hole 13 to pin on RGB module labelled R
	5. Connect Hole 12 to pin on RGB module labelled G
	6. Connect Hole 11 to pin on RGB module labelled B
	7. Connect GND Hole to the pin on RG module labelled '-'
	8. Upload code and run
