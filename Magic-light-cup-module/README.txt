Magic Light cup
----------------------------------------
Description:
    Using Arduino to use a "magic light cup" or a red LED with a pre-existing tilt switch attached to it
----------------------------------------
Components
    ->Arduino UNO board (microcontroller)
    ->Arduino IDE (program)
    ->M wires, F wires
    ->Magic light cup Module (Robocraze 37 in 1 sensor kits)
-----------------------------------------
Logic:
    View Logic.pdf
-----------------------------------------
Steps:
    1. Connect Arduino uno to computer.
    2. Connect IDE to board.
    3. Enter Code into IDE.
    4. For button, connect S pin to slot 2 in arduino, the '-' pin into GND, the '+' pin into 5V slot in Arduino, and L pin to slot 3.
    6. Upload the code.
